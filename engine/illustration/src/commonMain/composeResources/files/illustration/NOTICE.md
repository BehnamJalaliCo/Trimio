# Illustration library — sources and licences

`people.json` and `objects.json` are built by `engine/illustration/tools/build_library.py` (people pieces
rendered to SVG by `tools/peeps.js`). Numbers in path data are rounded (1 decimal for people, 2 for objects);
the drawings are otherwise unchanged. Keywords (English and Persian) are written for Trimio.
