# Core set and shipped catalogues (files/core)

Built by tools/packs/build_art_packs.py --core. Not shown in the app.

- art.json: the most used Noto Animated Emoji (Google, CC BY 4.0, https://googlefonts.github.io/noto-emoji-animation/)
  and the animated Material Line Icons (line-md, Vjacheslav Trushkin, MIT, https://github.com/cyberalien/line-md);
  keywords from Unicode CLDR emoji annotations (Unicode License v3).
- online.json: catalogue rows (names and keywords only) of SVG Spinners (Utkarsh Verma, MIT) and EOS Icons (SUSE UX/UI team, MIT).
- index.json: the signed manifests of the content channel at build time.
