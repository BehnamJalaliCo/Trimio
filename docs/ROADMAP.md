## فاز ۰ — امنیت دارایی‌ها و سیستم تایپوگرافی ✅

- [x] فونت‌های دارای مجوز فقط رمزشده در مخزن (`brand/assets.bin`، AES-256-GCM)؛ کلید هرگز در گیت نیست
- [x] رمزگشایی هنگام بیلد با کلید از Secret یا فایل محلی؛ بدون کلید، بیلد با فونت باز ادامه می‌دهد
- [x] فایل مجوز هر خانواده داخل بستهٔ اپ (طبق شرط مجوز)، بدون هیچ اشاره‌ای در رابط کاربری
- [x] چهار نقش تایپوگرافی: رابط (متغیر ۱۰۰ تا ۱۰۰۰ + محور نقطه)، بیانی (متغیر)، نمایشی (۱۱ وزن)، تأکیدی (۶ وزن)
- [x] اتصال به سیستم طراحی (`Trimio.type.families`) و نمونهٔ تایپوگرافی برای بازبینی
- [ ] ثبت Secret `TRIMIO_BRAND_KEY` در گیت‌هاب (مالک)
- [x] تأیید مالک

## فاز ۱ — هویت بصری پرمیوم «سیگنیچر» ✅
- [x] سه جهت کاملاً متفاوت (نوآر آتلیه، لومن، کینتیک پیپر)، هر کدام با ۴ صفحهٔ کلیدی
- [x] تلفیق ارتقایافته «سیگنیچر» و تأیید مالک — [`design/`](design/)
- [x] قانون سه رنگ تأکید: نارنجی = اقدام، لیمویی = تأکید در محتوا، رنگین‌کمانی = فقط کارگردان
- [x] توکن‌ها در کد: رنگ (تم تیره «نوآر» و روشن «کاغذ»)، مقیاس تایپ، فاصله و شکل
- [x] اجزای پایه: دکمه، شیشهٔ گرم (با حالت «روی تصویر»)، چیپ، خط مو، نشان کارگردان، متن تأکیدی، متن نمایشی با جعبهٔ خط دقیق
- [x] کنترل پیکسلی: خانه در Compose کنار طرح؛ ۹۲٪ پیکسل‌های رابط منطبق (باقی: لبه‌صافی متن و دانهٔ فیلم)
- [x] رفع دو اشکال تم روشن پیدا شده در بازبینی: متن روی تصویر و چیپ لیمویی

## فاز ۲ — طراحی همهٔ صفحه‌ها ✅
- [x] کیت مشترک سیگنیچر برای طراحی (رنگ، تایپ، اجزا، آیکون‌ها) تا همهٔ صفحه‌ها یک زبان باشند
- [x] برد ۱: آنبوردینگ (۳ مرحله)، خانهٔ خالی، خانه با پروژه‌ها
- [x] برد ۲: ساخت پروژه، انتخاب ۲۸ سبک، استریم ساخت، آماده شد، خطای صادق و قابل اقدام
- [x] برد ۳: ادیتور با ۵ ابزار (متن، سبک، صدا، المان، برش)
- [x] برد ۴: خروجی، گالری سبک‌ها، تنظیمات، مدل‌ها، حالت بدون اینترنت
- [x] برد ۵: تم روشن برای صفحه‌های اصلی
- [x] حرکت: ورود خانه و استریم زنده (ویدیو ۶۰ فریم) — [`design/motion/`](design/motion/)
- [x] قانون‌های تازه از بازبینی تم روشن: جوهر عمیق‌تر کارگردان، لیمویی فقط به‌صورت بلوک، رنگ «زنده» جداگانه (در کد هم اعمال شد)
