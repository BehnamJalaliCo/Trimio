- [x] انیمیشن فارسی بدون شکستن اتصال حروف (ماسک در جهت خواندن، بدون letter-spacing)
- [x] پس‌زمینه‌ها: aurora (شیدر)، gradient، mesh، grid، waves (ویژوالایزر صدا)
