## فاز ۱ — هویت بصری پرمیوم «سیگنیچر» ✅
- [x] سه جهت کاملاً متفاوت (نوآر آتلیه، لومن، کینتیک پیپر)، هر کدام با ۴ صفحهٔ کلیدی
- [x] تلفیق ارتقایافته «سیگنیچر» و تأیید مالک — [`design/`](design/)
- [x] قانون سه رنگ تأکید: نارنجی = اقدام، لیمویی = تأکید در محتوا، رنگین‌کمانی = فقط کارگردان
- [x] توکن‌ها در کد: رنگ (تم تیره «نوآر» و روشن «کاغذ»)، مقیاس تایپ، فاصله و شکل
- [x] اجزای پایه: دکمه، شیشهٔ گرم (با حالت «روی تصویر»)، چیپ، خط مو، نشان کارگردان، متن تأکیدی، متن نمایشی با جعبهٔ خط دقیق
- [x] کنترل پیکسلی: خانه در Compose کنار طرح؛ ۹۲٪ پیکسل‌های رابط منطبق (باقی: لبه‌صافی متن و دانهٔ فیلم)
- [x] رفع دو اشکال تم روشن پیدا شده در بازبینی: متن روی تصویر و چیپ لیمویی

## فاز ۳ — زبان موشن ✅ (در انتظار تأیید)
ماژول `engine/motion` در چهار لایه:
- [x] لایهٔ ۰ — موتور: کی‌فریم با منحنی‌های حرفه‌ای (expo، فنر، back، bezier، نویز)، لایه، گروه، ماسک، ترکیب رنگ، چرخش سه‌بعدی با پرسپکتیو، دوربین (push، ضربه، لرزش)، بلور، موشن‌بلور فیلمی، مسیر با draw-on، گرادیان زنده، دانهٔ فیلم، وینیت، light leak، فلش، اسکریم، گرید، فوتیج با اصلاح رنگ
- [x] متن حرف‌به‌حرف و کلمه‌به‌کلمه بدون شکستن اتصال حروف فارسی، خطوط متوازن، هایلایت بلوکی با تغییر رنگ متن، زیرخط، رنگ کارائوکه، دایرهٔ دست‌کشیده؛ خط پایه از جوهر واقعی حروف اندازه‌گیری می‌شود
- [x] لایهٔ ۲ — ۱۷ رسپی با کیفیت طراح ارشد: ۹ حرکت متن (mask-rise، slam، کپشن پاپ، تایپ، blur-in، flip، spread، پوستر، گلیچ) و ۸ المان (شمارنده، تیکر قیمت، نمودار، میله‌ای، آیکون، lower-third، مهر، چک‌لیست) + ۳ لوک (نوآر، کاغذ، لومن)
- [x] لایهٔ ۳ — Score: JSON کوچک و بخشنده که کوچک‌ترین مدل هم درست می‌نویسد (ارجاع به کلمه با شماره یا نقل‌قول، نام‌های تقریبی)
- [x] کامپایلر: زمان‌بندی روی گفتار با دو فریم جلوتر، چسباندن ضربه‌ها به ضرب موسیقی، حداقل زمان خوانایی، چیدمان بدون برخورد در ناحیهٔ امن، فیت متن، کپشن که برای تیتر کنار می‌رود، یک هایلایت در هر خط، ترنزیشن‌ها با صدا، لیست افکت صوتی
- [x] کارگردان خودکار برای صحنه‌های خالی: هوک، اعداد گفته‌شده (فارسی/انگلیسی) به شمارنده، آیکون کلمات کلیدی
- [x] نمونهٔ ریلز سیگنال بیت‌کوین: یک بار با Score کوتاه، یک بار کاملاً خودکار (`docs/design/motion/3-*.mp4`)
- [ ] رندر GPU روی گوشی (۶۰ فریم تا 4K) → فاز ۸؛ الان رندر نرم‌افزاری Skia، حدود ۰٫۳ ثانیه برای هر فریم روی سرور تست
- [ ] شیدرهای سفارشی و اعوجاج → فاز ۶

- [x] ۵.۳ دانش با اینترنت: لوگوی برندهای غایب، تصویر و فکت، قیمت کریپتو؛ بدون اینترنت از پک‌های آفلاین

- [x] ۵.۵ منتقدها: منتقد ساختاری، منتقد بینایی (جعبهٔ صورت و خواندن متن) و **هیئت ده داور** با حلقهٔ اصلاح و نسخه‌های جایگزین؛ تحویل فقط وقتی همه ۱۰ بدهند (با بودجهٔ هر دستگاه)
- [x] ۵.۶ همکاری دوطرفه: بازخورد متنی و یادگیری سلیقه (`Taste`، `Collaborator`)
- [x] ۵.۷ حالت یک‌لمسی: ویدیو یا صدا + پرامپت → خروجی کامل و مسترشده
- [x] کیفیت: کنتراست تضمین‌شده (۴٫۵:۱) روی هر فوتیج، تشخیص سوژهٔ مقاوم، لیمیتر پیک واقعی، ‎-14 LUFS
- [x] محک: ویدیوی واقعی ۲ از هر ده داور ۱۰ (تأیید مالک: ۱۰ از ۱۰)؛ کارگاه ۲۱ سناریو و آرشیو طلایی: ۲۰ از ۲۱ با نمرهٔ کامل
