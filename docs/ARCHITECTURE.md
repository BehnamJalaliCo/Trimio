# معماری Trimio

> اپ موشن‌گرافی و ادیت خودکار. ورودی: **ویدیو یا فقط صدا** + پرامپت ساده یا پیچیده.
> خروجی: ویدیوی ادیت‌شده با زیرنویس کلمه‌به‌کلمه، المان، افکت صوتی و موشن‌گرافی در ۲۸ سبک.

## ۱. اصول

| اصل | تصمیم |
|---|---|
| پلتفرم فعلی | اندروید ۱۳+ (minSdk 33)، فقط گوشی‌های قوی (رم ۸ گیگ به بالا + Vulkan) |
| پلتفرم‌های آینده | iOS و وب — به همین دلیل همه‌چیز روی **Kotlin Multiplatform + Compose Multiplatform** است |
| هوش مصنوعی | بدون اشتراک. مدل‌های آفلاین روی گوشی + کلید API اختیاری کاربر (Claude / OpenAI) |
| زبان‌ها | فارسی و انگلیسی، طراحی راست‌به‌چپ از پایه |
| قطعیت | ورودی یکسان + `seed` یکسان ← خروجی یکسان |

## ۲. ورودی‌ها

| حالت | توضیح |
|---|---|
| `InputSource.Video` | ویدیو + صدای خودش. موشن‌گرافی روی ویدیو قرار می‌گیرد. |
| `InputSource.AudioOnly` | فقط صدا (پادکست، ویس، موسیقی). **بوم (Canvas) کامل توسط سبک ساخته می‌شود**: پس‌زمینهٔ متحرک، تایپوگرافی، المان‌ها و ویژوالایزر صدا. نسبت تصویر را کاربر یا کارگردان انتخاب می‌کند. |

## ۳. لایه‌ها

```
androidApp (فقط اندروید: Activity، سرویس پیش‌زمینه، دسترسی‌ها)
   │
shared (ریشهٔ UI، DI با Koin، ناوبری) ← در آینده iosApp و webApp هم از همین استفاده می‌کنند
   │
feature/*   (stream، studio، prompt، gallery، editor، export)
   │
core/designsystem   (Trimio DS: توکن‌ها، شیدرها، کامپوننت‌ها)
core/pipeline       (Orchestrator، مراحل، پیشرفت وزن‌دار، چک‌پوینت)
core/model          (Timeline DSL، رونوشت، سبک‌ها، ورودی‌ها)
   │
engine/*  (پیاده‌سازی پلتفرمی پشت رابط‌های مشترک)
   media    : Media3 (اندروید) │ AVFoundation (iOS) │ WebCodecs (وب)
   audio    : Resampler، EBU R128، VAD، YIN، تأکید  (Kotlin مشترک)؛ RNNoise/Silero بعداً native
   asr      : whisper.cpp + تراز CTC                             (C++ مشترک)
   llm      : llama.cpp (JNI، گرامر GBNF) + Claude (SDK رسمی Java) + OpenAI (HTTP)
   director : Brief، موتور قوانین، LLM، ترکیب تایم‌لاین، کنترل کیفیت  (Kotlin مشترک)
   render   : Skia + Skottie + Filament + شیدرها                  (C++ مشترک)
   mixer    : میکس، داکینگ، رمزگذاری AAC
```

تحلیل صدا به‌جای C++ با Kotlin مشترک نوشته شده: روی همهٔ پلتفرم‌ها یکسان است، روی JVM تست می‌شود و سرعتش کافی است (۱۰ دقیقه صدا در حدود ۳ ثانیه). فقط مدل‌های عصبی (Whisper، RNNoise، LLM) native هستند.

قاعده: `core/*` و `feature/*` هیچ وابستگی پلتفرمی ندارند. هر چیز پلتفرمی پشت یک `interface` در `core` تعریف و در `engine/*` پیاده می‌شود.

## ۵. کارگردان (Director)

```
پرامپت ──► BriefParser (قطعی، دوزبانه) ──► StyleMatcher ──► RulesDirector ──► پیش‌نویس EditPlan
                                                                         │
                     LanguageModel (Claude / OpenAI / llama.cpp روی گوشی) ┘  بهبود پیش‌نویس
                                                                         ▼
                                 PlanSanitizer ──► EditPlan نهایی ──► TimelineComposer ──► QualityControl ──► Timeline + StyleSpec
```

1. **Brief**: سبک نام‌برده، حس و انرژی، موضوع (کریپتو، فارکس، آموزش…)، «بدون موزیک/کات»، کلمات «نقل‌قول‌شده»، عنوان — بدون هیچ مدلی
2. **پیش‌نویس قطعی**: تأکید (پروسودی + عدد + واژگان موضوع)، المان کلمه‌به‌کلمه (شمارنده برای عدد گفتاری، نمودار برای حرکت بازار، آیکون، برچسب)، Hook / CTA، حس موسیقی
3. **LLM** فقط تصمیم می‌گیرد، نه زمان‌بندی: خروجی‌اش `EditPlan` فشرده روی شمارهٔ کلمه‌هاست. مدل محلی با گرامر GBNF و مدل ابری با Structured Output محدود می‌شوند؛ هر خروجی از `PlanSanitizer` می‌گذرد و خواستهٔ صریح کاربر همیشه برنده است
4. **ترکیب**: کات سکوت و مکث (حاشیهٔ امن دو طرف کلمه)، نگاشت همه‌چیز به زمان خروجی با `EditMap`، طراحی صدا از نقشهٔ رویداد سبک
5. **کنترل کیفیت**: کنتراست WCAG، سایه روی فوتیج، حداقل زمان نمایش، مناطق امن Reels/TikTok/Shorts، `TimelineValidator` با ترمیم خودکار
6. **Fallback**: ابر ← مدل روی گوشی ← موتور قوانین. رد درخواست، کلید نامعتبر، قطع اینترنت یا خروجی خراب هرگز ادیت را متوقف نمی‌کند و دلیلش به کاربر گفته می‌شود

## ۶. سبک‌ها

۲۸ سبک در ۶ خانوادهٔ موتوری: `Vector2D`، `ShaderFx`، `Typography`، `TextureCollage`، `ThreeD`، `Organic`.
هر سبک یک **پکیج دادهٔ امضاشده** است (tokens، motion، components، shaders، sfx-map، rules) و بدون آپدیت اپ اضافه می‌شود. پکیج‌ها کد اجرایی ندارند (سیاست گوگل‌پلی).

## ۷. مدل‌ها

| سطح | مدل (GGUF، Q4_K_M) | حجم | رم |
|---|---|---|---|
| پیش‌فرض کارگردان | Qwen3.5-4B | ۲.۷ گیگ | ۸ گیگ |
| خلاق | Gemma 4 E4B (QAT) | ۵.۲ گیگ | ۱۲ گیگ |
| MoE سریع | LFM2.5-8B-A1B | ۵.۲ گیگ | ۱۲ گیگ |
| حرفه‌ای | Qwen3.5-9B | ۵.۷ گیگ | ۱۶ گیگ |
| ابری | Claude Opus 5.5 / OpenAI با کلید کاربر | — | — |
| گفتار | Whisper small / large-v3-turbo (q5/q8) | ۰.۳–۰.۹ گیگ | ۸–۱۶ گیگ |

مدل‌ها هم‌زمان در رم نگه داشته نمی‌شوند؛ هر موتور فقط در مرحلهٔ خودش بارگذاری و بعد آزاد می‌شود (`LanguageModel.release()`).
whisper.cpp و llama.cpp دو کتابخانهٔ جدا (`libtrimio_whisper.so`، `libtrimio_llama.so`) با یک نسخهٔ ggml و نمادهای مخفی‌اند.
