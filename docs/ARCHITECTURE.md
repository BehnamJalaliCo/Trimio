# معماری Trimio

> اپ موشن‌گرافی و ادیت خودکار. ورودی: **ویدیو یا فقط صدا** + پرامپت ساده یا پیچیده.
> خروجی: ویدیوی ادیت‌شده با زیرنویس کلمه‌به‌کلمه، المان، افکت صوتی و موشن‌گرافی در ۲۸ سبک.

## ۱. اصول

| اصل | تصمیم |
|---|---|
| پلتفرم فعلی | اندروید ۱۳+ (minSdk 33)، فقط گوشی‌های قوی (رم ۸ گیگ به بالا + Vulkan) |
| پلتفرم‌های آینده | iOS و وب — به همین دلیل همه‌چیز روی **Kotlin Multiplatform + Compose Multiplatform** است |
| هوش مصنوعی | بدون اشتراک. مدل‌های آفلاین روی گوشی + کلید API اختیاری کاربر (Claude / OpenAI) |
| زبان‌ها | فارسی و انگلیسی، طراحی راست‌به‌چپ از پایه |
| قطعیت | ورودی یکسان + `seed` یکسان ← خروجی یکسان |

## ۲. ورودی‌ها

| حالت | توضیح |
|---|---|
| `InputSource.Video` | ویدیو + صدای خودش. موشن‌گرافی روی ویدیو قرار می‌گیرد. |
| `InputSource.AudioOnly` | فقط صدا (پادکست، ویس، موسیقی). **بوم (Canvas) کامل توسط سبک ساخته می‌شود**: پس‌زمینهٔ متحرک، تایپوگرافی، المان‌ها و ویژوالایزر صدا. نسبت تصویر را کاربر یا کارگردان انتخاب می‌کند. |

## ۳. لایه‌ها

```
androidApp (فقط اندروید: Activity، سرویس پیش‌زمینه، دسترسی‌ها)
   │
shared (ریشهٔ UI، DI با Koin، ناوبری) ← در آینده iosApp و webApp هم از همین استفاده می‌کنند
   │
feature/*   (stream، studio، prompt، gallery، editor، export)
   │
core/designsystem   (Trimio DS: توکن‌ها، شیدرها، کامپوننت‌ها)
core/pipeline       (Orchestrator، مراحل، پیشرفت وزن‌دار، چک‌پوینت)
core/model          (Timeline DSL، رونوشت، سبک‌ها، ورودی‌ها)
   │
engine/*  (پیاده‌سازی پلتفرمی پشت رابط‌های مشترک)
   media    : Media3 (اندروید) │ AVFoundation (iOS) │ WebCodecs (وب)
   audio    : RNNoise، libebur128، Silero VAD، تحلیل Pitch/انرژی  (C++ مشترک)
   asr      : whisper.cpp + تراز CTC                             (C++ مشترک)
   llm      : llama.cpp (OpenCL/Vulkan/Hexagon) + آداپتور ابری
   render   : Skia + Skottie + Filament + شیدرها                  (C++ مشترک)
   mixer    : میکس، داکینگ، رمزگذاری AAC
```

قاعده: `core/*` و `feature/*` هیچ وابستگی پلتفرمی ندارند. هر چیز پلتفرمی پشت یک `interface` در `core` تعریف و در `engine/*` پیاده می‌شود.

بعد از هر مرحله چک‌پوینت ذخیره می‌شود؛ اگر اپ بسته شود کار از آخرین مرحلهٔ کامل ادامه پیدا می‌کند.

## ۵. کارگردان (Director)

1. **Brief**: برداشت هدف، مخاطب و حس از پرامپت (LLM)
2. **ساختار روایت**: Hook / بدنه / CTA
3. **تصمیم کلمه‌به‌کلمه**: قوانین سبک + LLM + جست‌وجوی معنایی المان و صدا
4. **کنترل کیفیت**: منطقهٔ امن شبکه‌های اجتماعی، کنتراست، سرعت خواندن، عدم تداخل
5. **خروجی**: `Timeline` (JSON نسخه‌دار) — منبع واحد برای پیش‌نمایش، خروجی و XML پریمیر

خروجی LLM همیشه با اسکیمای `Timeline` اعتبارسنجی می‌شود؛ در صورت خطا قوانین قطعی جایگزین می‌شوند.

## ۶. سبک‌ها

۲۸ سبک در ۶ خانوادهٔ موتوری: `Vector2D`، `ShaderFx`، `Typography`، `TextureCollage`، `ThreeD`، `Organic`.
هر سبک یک **پکیج دادهٔ امضاشده** است (tokens، motion، components، shaders، sfx-map، rules) و بدون آپدیت اپ اضافه می‌شود. پکیج‌ها کد اجرایی ندارند (سیاست گوگل‌پلی).

مدل‌ها هم‌زمان در رم نگه داشته نمی‌شوند؛ هر موتور فقط در مرحلهٔ خودش بارگذاری می‌شود.
