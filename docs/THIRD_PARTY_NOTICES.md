## Desktop installers only: FFmpeg

| Component | Build | Licence |
|---|---|---|
| FFmpeg `ffmpeg.exe` / `ffprobe.exe` (Windows x64) | BtbN/FFmpeg-Builds, `win64-lgpl` variant, pinned by sha256 in `desktopApp/ffmpeg/windows.properties` | LGPL-2.1-or-later |

- The bundle is built **without** `--enable-gpl` / `--enable-nonfree`: no libx264, libx265 or other
  GPL-only libraries. CI fails the Windows build if `ffmpeg -buildconf` shows either flag or if
  libx264 is present (`.github/workflows/desktop-windows.yml`).
- H.264 is encoded by Windows' own Media Foundation encoder through FFmpeg's `h264_mf` wrapper;
  Microsoft licenses that codec with the operating system. AAC uses FFmpeg's native encoder.
- The executables are unmodified, shipped next to the app with FFmpeg's `LICENSE.txt` and a
  `SOURCE.txt` naming the exact build; its source is the FFmpeg release branch in that name.
  Because Trimio only runs them as separate processes, the LGPL places no terms on Trimio's code.
- Development machines and the Linux CI may use a GPL ffmpeg with libx264 from the PATH; that
  binary is never distributed. If a future build ever bundles libx264, the bundled ffmpeg becomes
  GPL-2.0-or-later: it would still be a separate program (mere aggregation), but the installer
  must then carry the GPL text and an offer of the exact FFmpeg + x264 source, and the x264
  commercial licence question has to be settled first. See docs/DESKTOP.md.

### Music and SFX sourcing decision (phase 6.2 / 6.3)

The repository is public and the app is commercial, so a third-party sound may only ship if its
licence allows commercial redistribution *inside an app* (not only use in a video), with no
attribution duty that passes to user exports. Reviewed and **not used**:

| Source | Why not |
|---|---|
| Pixabay Music / SFX (Pixabay Content License) | forbids standalone redistribution of the files (an in-app sound library is that); some tracks are Content ID-registered, so user uploads can be claimed |
| Freesound | per-file licences, mostly CC-BY / CC-BY-NC; CC0 files exist but provenance is uploader-asserted |
| YouTube Audio Library, Incompetech (CC-BY), Free Music Archive | attribution required or redistribution not granted |
| Mixkit, Uppbeat, Epidemic, Artlist | licence covers use in a production, not redistribution inside software (Uppbeat free tier also needs credit) |

Decision: everything is composed and synthesised in code (sections, drums, bass, pads, risers,
layered hits), so exports carry no third-party terms. Recorded packs may be added later only as
**CC0-1.0** with a verified original author, delivered as signed downloadable packs
(`PackManifest.license` must name the SPDX id; the server refuses anything else) and listed here.

### Animated pictures (phase 8b)

Unlike sounds, the director may now put third-party **animated pictures** into an edit. Only
licences that allow commercial use inside an app and in the creator's exported video pass

NonCommercial, NoDerivatives and unknown licences never enter the catalogue. Details and the
sources reviewed and rejected (OpenMoji, Pexels, Pixabay, Wikimedia Commons):
`docs/ASSETS.md`, "Animated pictures". Free LottieFiles animations are fetched on demand, a few at
a time, under the Lottie Simple License (commercial use, no credit required).
