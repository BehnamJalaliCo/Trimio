### Music and SFX sourcing decision (phase 6.2 / 6.3)

The repository is public and the app is commercial, so a third-party sound may only ship if its
licence allows commercial redistribution *inside an app* (not only use in a video), with no
attribution duty that passes to user exports. Reviewed and **not used**:

| Source | Why not |
|---|---|
| Pixabay Music / SFX (Pixabay Content License) | forbids standalone redistribution of the files (an in-app sound library is that); some tracks are Content ID-registered, so user uploads can be claimed |
| Freesound | per-file licences, mostly CC-BY / CC-BY-NC; CC0 files exist but provenance is uploader-asserted |
| YouTube Audio Library, Incompetech (CC-BY), Free Music Archive | attribution required or redistribution not granted |
| Mixkit, Uppbeat, Epidemic, Artlist | licence covers use in a production, not redistribution inside software (Uppbeat free tier also needs credit) |

Decision: everything is composed and synthesised in code (sections, drums, bass, pads, risers,
layered hits), so exports carry no third-party terms. Recorded packs may be added later only as
**CC0-1.0** with a verified original author, delivered as signed downloadable packs
(`PackManifest.license` must name the SPDX id; the server refuses anything else) and listed here.
