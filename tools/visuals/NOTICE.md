# Visual vocabulary — sources and licences

The packs built by `build_visuals.py` (and `../brands/build_pack.py`) contain artwork from these
open sets, redistributed under their licences:

| Set | Licence | Source |
|---|---|---|
| Fluent Emoji Flat | MIT, © Microsoft | https://github.com/microsoft/fluentui-emoji |
| Health Icons | MIT | https://github.com/resolvetosavelives/healthicons |
| Material Design Icons | Apache-2.0, © Pictogrammers | https://github.com/Templarian/MaterialDesign |
| Tabler Icons | MIT, © Paweł Kuna | https://github.com/tabler/tabler-icons |
| Simple Icons (brand marks) | CC0-1.0 | https://github.com/simple-icons/simple-icons |
| Emoji keywords (emojibase-data, CLDR) | MIT | https://github.com/milesj/emojibase |

Sets are fetched through Iconify's npm packages (`@iconify-json/<set>`). Brand marks are
trademarks of their owners and appear only in a user's own content about those products.
